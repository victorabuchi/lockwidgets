No data collected

No account, no analytics. Weather comes from Open-Meteo, lyrics from Music on your Mac, and notifications are read from macOS's own database without leaving it.

Notarized by Apple

Every release is signed with a Developer ID and scanned by Apple before it reaches you, so it opens like any other app.

Signed updates

Notchlight checks for a new version once a day and asks before installing it. Your Mac only accepts updates signed by Notchlight.

Install

Ready in a minute.

  1. Download Notchlight.dmg and open it.
  2. Drag Notchlight into Applications, then open it.
  3. Pick your first widgets in the Setup Guide.
  4. Lock your Mac with ⌃ ⌘ Q to see them.

Questions
Is Notchlight free?

Yes. Every widget and the Dynamic Island are free, with no account and no subscription.

Why isn't it on the Mac App Store?

Mac App Store apps run in Apple's sandbox, which doesn't allow drawing over the lock screen or reading notifications. Notchlight is signed with a Developer ID and notarized by Apple instead, so it installs and opens like any other app.

Is it safe?

Apple scans every release for malware before notarizing it, and updates are signed so your Mac only installs ones that come from Notchlight. The source code is on GitHub.

Which Macs does it work on?

Any Mac with macOS 15 or later. The Dynamic Island is made for MacBooks with a notch; on other Macs it shows up only while something is live.

Does it work with Spotify?

Yes: the song playing in Spotify shows in the island and on the lock screen, with its artwork and controls. Synced lyrics come from Apple Music only.

What permissions does it ask for?

Only what your widgets use: Calendar, Reminders, Location for weather, Photos, and Automation to read the song in Music or Spotify. Notifications on the island need Full Disk Access, because macOS keeps them in a protected file. The Setup Guide takes you to each one.

How do updates work?

Notchlight looks for a new version once a day and asks before installing it. Choose Check for Updates… in its menu to look now. With Homebrew, brew upgrade works too.

How do I uninstall it?

Quit Notchlight from its menu bar icon and drag it from Applications to the Trash. With Homebrew, run brew uninstall --cask notchlight.
